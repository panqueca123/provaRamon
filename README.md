# JOGO DA COBRINHA

    O jogo da cobrinha é um jogo online muito conhecido.
    O jogo se trata de uma cobra que se movimenta pela tela tentando comer a 'comida',
    se a cobra come ela cresce de tamanho, se bate na parede ou no próprio corpo, morre.
    Com as teclas A, W, D, S você consegue se movimentar pela tela.
    'W' cima
    'S' baixo
    'A' esquerda
    'D' direita
